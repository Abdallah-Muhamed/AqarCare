## 🔗 API Endpoints Summary

### Public (no auth)
- GET  /api/properties                  — list with filters + pagination
- GET  /api/properties/{id}             — property detail + media
- GET  /api/finishing-packages          — package cards list
- GET  /api/finishing-packages/{idOrSlug} — full package detail

### Admin (X-Api-Key header required — default: "aqarcare-dev-admin-key-change-me")
- POST   /api/admin/properties              — create property
- PUT    /api/admin/properties/{id}         — update property
- DELETE /api/admin/properties/{id}         — delete property
- POST   /api/admin/properties/{id}/media   — link media to property
- DELETE /api/admin/properties/{id}/media/{mediaId} — remove media
- POST   /api/admin/finishing-packages      — create package
- PUT    /api/admin/finishing-packages/{id} — update package
- DELETE /api/admin/finishing-packages/{id} — delete package
- POST   /api/admin/media/upload            — upload to Cloudinary
- DELETE /api/admin/media/{publicId}        — delete from Cloudinary
